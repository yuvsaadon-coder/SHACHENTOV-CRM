# הצעות מחיר מספקים · איך זה עובד

**נוסף:** 19.11.2026, לבקשת הבעלים. לשונית "הצעות מחיר" בלוח האדמין.

## מה זה עושה
1. האדמין בוחר ספק ומעלה הצעת מחיר אחת או יותר: אקסל (xlsx), CSV, PDF או תמונה (צילום של הצעה).
2. המערכת קוראת את ההצעה ומציעה לכל שורה אחת משלוש פעולות: **עדכן מחיר** של מוצר קיים, **הוסף מוצר חדש** עם אייקון וקטגוריה, או **התעלם**.
3. מסך בדיקה: אפשר לשנות כל פעולה, להחליף את המוצר המותאם, לתקן מחיר, שם או אייקון. מוצג אחוז השינוי מול המחיר הנוכחי (חץ וטקסט, לא רק צבע), ושורות לא ודאיות מסומנות "כדאי לבדוק".
4. **שום דבר לא משתנה עד הלחיצה על "החל"**. אחרי האישור הקטלוג מתעדכן, וההצעה נרשמת בהיסטוריה: מתי, איזה ספק, אילו קבצים, ומה השתנה (מחיר ישן וחדש). הקבצים עצמם לא נשמרים.

**מע"מ:** המחירים בקטלוג כוללים מע"מ. ההצעה יכולה לציין "לפני מע"מ" (אז יתווספו 18%) או "כולל מע"מ". אפשר להשאיר זיהוי אוטומטי, או לקבוע ידנית גם במסך הבדיקה.

**אם יש הצבעות בסבב הפתוח** מוצגת אזהרה, כי בשלב הזה מחיר חדש משנה גם את חישוב התוצאות של הסבב.

## שתי דרכים לקרוא הצעה
| | ניתוח חכם (AI) | קריאה בלי AI |
|---|---|---|
| מתי | כשהוגדר מפתח Claude ב-Netlify | אוטומטית, כשאין מפתח (או באתר ההדגמה) |
| מה הוא קורא | הכול, כולל PDF סרוק ותמונות | אקסל, CSV ו-PDF עם טקסט. **לא תמונות** |
| התאמה לקטלוג | לפי משמעות ("פנה 500 גרם" = פסטה) | לפי דמיון שמות |
| אריזות | מחלק מחיר קרטון במספר היחידות ורושם הערה | לא. צריך לבדוק ידנית |
| עלות | תשלום ל-Anthropic לפי שימוש. הצעה רגילה עולה בערך כמה סנטים | חינם |

הניתוח החכם רץ בפונקציה של Netlify (`netlify/functions/analyze-quote.mts`), כך שהמפתח לא מגיע לדפדפן. גיליון ארוך נשלח בחלקים של 25 שורות, כדי שכל קריאה תסתיים בזמן ש-Netlify מאפשר.

## הפעלת הניתוח החכם (פעם אחת)
1. ב-[console.anthropic.com](https://console.anthropic.com) ← **API Keys** ← **Create Key**, ולהעתיק את המפתח. (אם כבר יש מפתח שמשמש את ה-CRM, אפשר להשתמש בו.)
2. Netlify ← האתר של מערכת ההצבעה ← **Site configuration** ← **Environment variables** ← **Add a variable**.
3. **Key:** `ANTHROPIC_API_KEY` · **Value:** המפתח. שמירה.
4. **Deploys** ← **Trigger deploy** ← **Deploy site**.

בלי השלב הזה הלשונית עובדת במצב "בלי AI", עם הודעה צהובה.
